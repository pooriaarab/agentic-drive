# agentic-drive rules

These rules bind every run of agentic-drive. They also bind agents that use it.

1. Trash before you purge. Purge deletes bytes for good.
2. Respect a denial. A `FORBIDDEN` error stays final.
3. Report failures as failures. No silent success follows a failed call.
4. Keep the owner on every call. Never act on another owner's items.

Pack: Store, sort, and share files and folders.
